SolStice: autonomous AI trader on Solana

Built with a team of three for the National Solana Hackathon 2026. An AI agent analyzes live SOL market data, decides BUY / SELL / HOLD, and records every decision on-chain together with a SHA-256 hash of its reasoning, so the agent's full history is publicly verifiable.

My role: blockchain engineer. I built the Solana smart contract in Rust with Anchor:

Non-custodial vault using PDAs, with deposit and withdraw instructions
execute instruction that records each AI decision as an on-chain TradeEvent (action, amount, price, reasoning hash, timestamp)
Agent authority registration and user-selectable Conservative / Aggressive strategies
Deployed and tested on Solana Devnet
